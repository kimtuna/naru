### 회차 32 — 사람이 차지한 칸 · `Claim` · REGROW ⑤⑥ · 등록 빠뜨리기 대조군
- **목록을 월드 밖에 냈다**: `Claim` 이 **이름 붙은 출처**를 모으고 월드는 여전히
  Callable 하나만 안다(`world.occupied = claim.covers`). `WorldState` 안에 if 로 쌓으면
  월드가 설치물·밭·길을 다 알게 되고, `_body_covers` 에 쌓으면 어느 회차가 조용히
  한 줄을 빼먹는다 — 새 설치물은 **남의 함수를 고치는 게 아니라 한 줄을 더한다**
- **계약은 선언과 배선을 가른 자리에 있다**: `Claim.KINDS` 에 적고 `add()` 로 꽂는다.
  안 맞는 것은 `missing()` 이 세고 **REGROW 가 진짜 씬에서** 읽는다(⑤). 월드가 **목록을
  거치는지**도 같이 본다 — 몸 하나를 바로 꽂으면 `missing()` 은 비어 있는데 설치물은
  영영 안 물어진다. 이 둘이 이 회차가 진짜로 만든 것이다
- **설치물이 없어도 다 잴 수 있다**(⑥): 살아 있는 `claim` 에 **가짜 설치물** 한 칸을
  꽂는다. **임자의 이름까지 본다** — 「안 자랐다」만 보면 몸이 막은 것과 구별이 안 돼서
  새 출처를 안 물어도 초록이다. 단위 검사는 **옆 칸이 자라는 것**을 같이 센다:
  설치물 하나가 온 섬의 재생을 멈춰도 「안 자란다」는 초록이다
- **가짜 설치물의 이름은 `KINDS` 밖에 둔다** — 검사가 꽂는 것을 선언에 섞으면
  아무도 안 꽂아도 `missing()` 이 비어서 ⑤ 가 통째로 무너진다
- **대조군이 두 번 헛돌았다**(GOTCHAS 대조군 절): 대조군을 써 넣는 python 이 heredoc 안
  python 의 `\n` 을 먼저 먹었다 — 안쪽이 SyntaxError 로 죽고 **코드는 멀쩡히 남는다.**
  탭은 살아남아 넷 중 둘만 깨졌다. 「게이트가 약하다」가 아니라 **아무것도 안 깨뜨렸다**
- 같이 고친 둘: `test_claim` 이 「빠진 것 0 개」로 세고 있었다(제작대가 선언되는 날
  엉뚱한 검사가 빨개진다) · REGROW 가 배선 때문에 죽어도 「설 자리를 못 잡았다」를 찍었다
- 실측: `REGROW ok (하루 1200 s · 나무 1.0일 · 비킨 뒤 1.0 s · 남은 벤 칸 0 ·
  차지 출처 2 종)` · `설치물 하루+1초 뒤 그대로 (임자 가짜 설치물) · 허문 뒤 나무` ·
  `TESTS 164 passed, 0 failed`(154 → 164) · `run-contract.sh` 30.7초 · `ALL GREEN` 9/9 ·
  `REDTEAM 11 잡음, 0 놓침`(`--only 회차 32` · 4분 15초) — **그중 둘은 단위 검사를
  전부 초록으로 남긴다**
- 남긴 것: **반경**(설치물이 화면에 서야 눈으로 정한다) · 다음은 **전체 화면 띠 최소화** ·
