### 회차 34 — 창을 게임 크기에 · 띠 0x0 (일지 번호 33)
- **띠는 창이 게임보다 커서 생긴다 — 창을 게임에 맞춘다.** `Display.fit_window()` 가 최대
  정수 배율 N 으로 창을 `논리 × N` 에 잡고 가운데 놓는다. 전체 화면을 그만뒀다.
  **「셋 중 둘만」이 틀렸다**(ⓐ띠 없음 ⓑ정수 배율 ⓒ같은 범위) — **고정인 것은 전체
  화면일 때뿐**이었다. 그림은 그대로다(3배·2880x1620·60.00 x 33.75). 더 준 건 테두리뿐
- **여태 게이트에 안 걸린 이유**: 「띠 = 0」 하나로는 **아무것도 안 잡는다** — override
  1920x1080 이 정확히 2배라 배선을 빼먹어도 0 이다. VIEW 가 **띠 0 · 배율 최대 · 자리
  가운데** 셋을 묻고 띠는 **창에서** 뺀다
- **대조군 ⑤ 를 두 번 놓쳤다**(GOTCHAS): ① 크기만 재고 자리를 안 봤다 — 그건 **자리만**
  움직인다(340 → 307) ② 기대값을 `Display.avail_rect()` 로 냈다 — **대조군이 고치는 그
  함수**라 「틀린 값끼리 같다」. **재는 쪽은 재이는 쪽의 말을 빌리면 안 된다**
- 실측: `창 2880x1620 @ 288,340 · 배율 3.00x · 띠 0x0 · 화면 남음 576x548` · `TESTS 175
  passed, 0 failed`(173 →) · `ALL GREEN` 9/9 · `REDTEAM 12 잡음, 0 놓침`(`--only` 이 묶음)
- 남긴 것: 다음 항목(**띠 0 을 게이트로**)은 대부분 했다 — **전체 판** 확인만 남았다 ·

### 회차 36 — 시계 흔들림은 **프레임 한 칸**이었다 · 허용치를 조였다 (일지 번호 35)
- **「부하에서 흔들린다」가 틀린 진단이었다.** 홀로 3판만 돌려도 `0.105 · 0.008 · 0.087` 로
  흔들린다 — 부하가 아니다. **재는 구간이 프레임에 한 칸 어긋나 있었다**: `SceneTree`
  스크립트의 `_process` 는 노드의 `_process` **보다 먼저** 도는데(`SceneTree::process` 가
  `MainLoop::process` 를 맨 앞에서 부른다), 게이트는 `world.now` 를 프레임 k 에서 읽고
  델타는 `k+1` 부터 더했다 ⇒ 오차 = `|delta[E] − delta[k]|`
- **왜 흔들림이 컸나**: k 가 이 판에서 **가장 느린 프레임**이다 — `_find_tree` 가 반지름
  40(≈6561칸)을 훑는 그 프레임이다. 그래서 오차가 거의 항상 **한 방향**(게임이 덜 흘렀다)
- **고친 것은 등식이다** — 델타를 `k` 에서 넣고 끝 프레임 `E` 는 **넣기 전에 끊는다**
  (`measure_regrow.gd`). 오차가 **`0.000000`** 이 됐다. 홀로 5판 · **12판 동시 12/12**
- **그래서 허용치를 키우는 게 아니라 조였다: 0.10 → 0.01.** 회차 30~34 는 흔들림을
  허용치로 덮으려고 `0.05 → 0.10` 으로 두 번 키웠다 — **원인이 아닌 곳을 두 번 만졌다**
- **조인 값만 잡는 대조군이 생겼다**(redteam ⑥): `world.tick(delta * 0.9)` — 하루가
  20분 → 22분인데 게임은 멀쩡히 돌고 나무도 자란다. 오차 `0.0337 / 0.337초` 라
  **옛 허용치 0.05·0.10 에서는 초록**이었다. 허용치를 되키우려는 회차는 여기서 빨개진다
- 찍는 줄도 고쳤다 — `게임 1202.58초`(하루를 감은 뒤의 값)를 보여 주고 있었다.
  오차만 맞고 **견준 두 값이 안 보였다**
- 실측: `REGROW 시계 0.302초 도는 동안 게임 0.302초 (오차 0.000000초 · 허용 0.01)` ·
  `TESTS 175 passed, 0 failed` · `HEADGATE ok 구간 7/7` · `ALL GREEN` 9/9 ·
  `REDTEAM 6 잡음, 0 놓침` (`--only 회차 30 다시 자란다`) · 표는 `NUMBERS.md` 15b
