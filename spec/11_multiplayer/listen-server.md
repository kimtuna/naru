# 리슨 서버

## 목적
- 전용 게임 서버 없이 멀티를 연다.

## 규칙
- **호스트 겸용 리슨 서버** — 별도 전용 게임 서버 없음
- 1·2단계(생활 · PvE)는 전부 유저 기계에서 돈다 — 호스트가 치팅해도 피해가 자기 섬 안에서 끝난다
- **PvP 만 유저 호스팅 불가** — 호스트가 참가자면 상대 위치를 전부 알아 시야 차단을 우회할 수 있다
- 친구 co-op 은 방 코드 + 중개/릴레이
- 원정 파티(4)는 섬 정원(12)보다 작다 → 탑승으로 갈린다
- 호스트 끊김 처리는 10_economy/item-lineage.md

## 수치
- 내 섬 정원 **12명**
- 원정 파티 **최대 4명**

## 수용 기준
- 13번째 접속은 거부된다

## 미정
- F-7 PvP 섬 설계 전부 (3순위, 판매 수익 이후)
- 네트워크 방식(ENet / Steam) · 릴레이 미정
