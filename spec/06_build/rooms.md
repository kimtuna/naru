# 방(Room) 시스템

## 목적
- 꾸미기가 곧 기능이 된다 (ONI 참고).

## 규칙
- **벽·문으로 닫힌 공간이 생기면 자동으로 방으로 인식**
- 방 안 **핵심 오브젝트 카테고리**가 방 종류를 정한다
  - 정확히 한 카테고리만 있고 요구 수량을 채우면 그 방
  - 0개거나 2개 이상 섞이면 **잡실** — 혜택 없음 (= 야외)

| 방 | 핵심 오브젝트 | 요구 |
|---|---|---|
| 주방 | 조리대 + 조리용 화로 | 둘 다 1개 이상 |
| 제작소 | 가공대 | 1개 이상 |
| 대장간 | 제련로 | 1개 이상 |
| 연구소 | 연구대 | 1개 이상 |
| 농장 | 밭 | 1개 이상 |
| 목장 | 목장 구역 | 1개 이상 |
| 광산 | 광산 오브젝트 | 1개 이상 (mine-room.md) |
- 조건이 깐깐한 이유: 헐거우면 방을 나눌 이유가 없어져 전부 하나로 뭉친다
- **방-상자 자동 연동** — 같은 방의 상자를 제작대가 재료로 쓴다. 기준은 거리가 아니라 **방 ID 일치**
- 방은 나중에 NPC 주민 배치 단위가 된다 (07_automation/npc-villagers.md)
- 방 혜택(기능)과 꾸미기(표현)는 다른 것이다 (decoration.md)

## 수치
- 없음

## 수용 기준
- 벽으로 완전히 닫히면 방이 생기고, 벽 하나를 헐면 방이 사라진다
- 가공대만 있는 닫힌 공간 → 제작소
- 가공대 + 제련로가 함께 있는 공간 → 잡실
- 조리대만 있고 화로가 없는 공간 → 주방이 아니다
- 다른 방 ID 의 상자는 제작 재료로 쓰이지 않는다
