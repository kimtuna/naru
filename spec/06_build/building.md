# 건축

## 목적
- 실내 맵 없이 야외에 구역을 나눠 짓는다.

## 규칙
- **전부 실외다** — 집을 지급하지 않는다. 코어 키퍼처럼 야외에 벽·문으로 구역을 나눈다
- 실내를 따로 만들면 화면 전환 + 별도 맵이 필요해 비용이 급격히 는다
- 벽·문으로 닫힌 공간 = 방 (rooms.md)
- 방문자 권한 기본값은 「못 건드림」 (11_multiplayer/permissions.md)
- 사람이 만든 것 둘레에는 자원이 재생하지 않는다 (03_world/resources-regrowth.md)

## 수치
- 없음

## 수용 기준
- 벽·문 설치와 철거가 가능하고, 설치한 칸은 통행이 막힌다 (문은 예외)
