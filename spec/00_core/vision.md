# 비전 · 설계 원칙

## 목적
- 결정이 충돌할 때 판단 기준. 모든 spec 은 이 문서의 파생이다.

## 규칙
- **원칙: 혼자서도 끝까지 갈 수 있다. 다만 모든 직업을 마스터할 시간이 없을 뿐이다.**
  - 교류는 강제가 아니라 경제적 압력(시간 비용)에서 나온다. 벽을 세우지 않는다.
- 원칙의 파생 넷
  - 직업은 여러 갈래 — 한 사람이 전부 자급하면 시장이 안 생긴다
  - 최종 장비 재료는 원정에서만 — 생활과 전투를 잇는 공급선
  - 생활 스킬 하나하나가 깊다 — 얕으면 마스터가 귀하지 않다
  - 서버 방문이 시장이자 로비 — 그래서 섬을 꾸밀 동기가 생긴다
- 목적은 「요소가 많다」가 아니라 **서로 다른 플레이 스타일이 한 경제 안에서 맞물리는 것**
- 최종 목표는 「완성된 자기 섬」(완벽한 자동화 + 집 꾸미기). 경제·원정·직업은 중간 동력이다
- 관통 규칙: **한 번 캐고 끝나는 자원이 없다** — 기르거나 · 짓거나 · 되풀이 수확한다
- 콘텐츠(시스템)를 먼저, 데코레이션은 나중에 대량 추가. 지속성은 꾸준한 업데이트가 만든다
- 플레이어의 「오늘 잘했다」는 전부 동등하다 (밭 완성 · 자동화 가동 · 희귀 광물 · 경매 판매 · 도감 · 집 꾸미기)
