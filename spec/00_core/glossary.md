# 용어집

## 목적
- spec 전체에서 같은 말을 같은 뜻으로 쓰기 위해.

## 규칙
| 용어 | 뜻 |
|---|---|
| 내 섬 | 플레이어의 월드. 시드 기반 생성. 원정 선착장이자 로비 |
| 원정 섬 | PvE 던전 섬. 갈 때마다 새로 생성 |
| 내부 재화 | 세션 서버 섬에서 나온 모든 자원과 그것으로 만든 모든 것. 따로 지정하지 않아도 저절로 재화가 된다. 검증 안 함 |
| 경계 재화 | 원정 광물·가죽과 그것이 들어간 것. 중앙 원장이 ID 로 추적, 경매장·직거래 가능 |
| 중앙 (관문) | 신원·ID 발행·원장·에스크로·수출 상한만 하는 서버. 게임 시뮬레이션 안 함 |
| 에스크로 | 중앙이 아이템을 잠가 두는 것. 원정 획득물·의뢰 재료에 쓴다 |
| 계보 | 경계 재화가 어떤 재료 ID 로 만들어졌는지의 기록 |
| 비밀 소금 | 희귀 자원 배치를 정하는 값. 중앙만 안다 |
| 수출 상한 | 시간·인원·완료 횟수로 자르는 경계 재화 발행량 한도 |
| 티켓 | 원정 입장권 겸 보험 겸 화폐 배수구 |
| 티켓 밸류 | 티켓 등급별 반입 장비 가치 상한. 이 안의 장비는 죽어도 안 잃는다 |
| 이로치 | 색이 특이한 개체. 낮은 확률, 개체마다 유일 |
| 도감 | 순수 수집 기록. 보상 없음, 전설 직업 승급 조건 |
| 방 | 벽·문으로 닫힌 공간. 핵심 오브젝트 카테고리로 종류가 정해진다 |
| 잡실 | 핵심 카테고리가 0개거나 2개 이상 섞인 방. 혜택 없음 |
| 방 ID | 방 판정 결과. 방-상자 연동은 거리 아닌 방 ID 일치로 판단 |
| 출력 버퍼 | 제작대에 완성품이 쌓이는 칸. 플레이어가 수령 |
| 포인트 예산제 | 같은 등급 장비는 스탯 총합이 같고 배분만 다르다 |
| 천장 | 강화가 일정 횟수 실패하면 다음이 확정 성공 |
| 일손 펫 | 초반에 잡는 펫. 플레이어 둘레의 떨어진 아이템을 주워 온다 |
| 전설 직업 | 직업 사다리 최상위. 남의 최종 장비를 제작·강화 |
| 호스트 | 리슨 서버를 여는 플레이어 |
| 게스트 | 남의 섬에 들어간 플레이어 |
| 서버장 | 월드를 만든 사람. 월드 설정을 바꾼다. 혼자면 자기 자신 |
| 절벽 | 높이 경계의 못 지나가는 칸. 스파이크 신발 또는 갈고리총이 있어야 오른다 |
| 기력 | 절벽에서 움직일 때 생기고 주는 수치. 다 쓰고 여유까지 넘기면 떨어진다 |
| 앵커 | 절벽 칸에 다는 소모품. 그 칸에서 기력이 회복된다 |
| 갈고리총 | 쏜 쪽으로 날아가 매달리는 도구. 「그래플링」이라 부르지 않는다 |
| 스킬체크 | 채집 미니게임. 원 위의 성공 구간에 도는 바늘이 들어올 때 좌클릭 |
