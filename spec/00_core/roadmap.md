# 로드맵 · 프로토타입 범위

## 목적
- 무엇을 어떤 순서로 만드는가. 프로토타입이 증명할 것을 고정한다.

## 규칙
### 로드맵
| 단계 | 무엇 | 새로 필요한 것 |
|---|---|---|
| 0. 프로토타입 | 디자인을 뺀 핵심 루프 | 없음 |
| 1. 힐링 세션 서버 | 생활 + 자동화 + 내 섬 (싱글) | 없음 |
| 2. 친구 co-op | 리슨 서버 + 방 코드 | 방 코드 중개/릴레이 (작음) |
| 3. PvE 원정 섬 | 섬 2종 + 중앙 원장 + 경매장 | 중앙 관문 (작음) |
| ← 얼리억세스 출시 | | |
| 4. 섬 추가 · 데코 대량 | 섬 3·4번, 가구·장식 | 없음 |
| 5. PvP 섬 | | 전용 서버 · 매치메이킹 · 안티치트 |
- 얼리억세스 원정 섬은 **2개** (1개는 적고 4개는 늦다)
- 데코레이션은 시스템 뒤 — 데코는 업데이트로 메울 수 있지만 시스템 공백은 못 메운다
- PvP 는 판매 수익으로. PvP 가 영영 안 와도 상품으로 성립해야 한다
- 전기 · 자동화는 얼리억세스 출시 범위 안이다

### 프로토타입 (확정)
- **목표: 「생활 → 보급 → 원정 → 재료 → 더 나은 생활」 한 회차를 끝까지 돌 수 있게 기능을 다 만든다**
- **재미는 기능을 다 만든 뒤 사람이 플레이해서 판단한다. 루프는 재미를 묻거나 판단하지 않는다** (사람 결정 2026-09-16)
- 그림은 색 네모여도 된다

| 넣는 것 | 최소 |
|---|---|
| 이동 · 조작 | **8방향** 이동 + 마우스 조준 + 좌클릭 도구 (사람 결정 2026-09-13) |
| 자원 | 나무 · 돌 · 광물 1종 |
| 도구 | 도끼 · 곡괭이 · 총 |
| 제작 | 제작대 1개 + 타이머 + 출력 버퍼 |
| 농사 | 밭 + 작물 1종 (일구고 · 심고 · 물 주고 · 수확) |
| 보급 | 버프 음식 1종 — 농장이 원정을 먹여 살린다는 증명 |
| 원정 | 침몰한 마을 축소판 — 들어가기 → 잔해 캐기 → 몰려오는 적 → 버티기 → 탈출 |
| 되돌아옴 | 원정 산출물 1종 → 더 좋은 도구 1종 |
| 시간 | 하루 20분 |

- **빼는 것**: 멀티 · 중앙 서버 · 경매장 · ID 계보 · 직업 · 의뢰 · 자동화/드론/NPC · 도감 · 이로치 · 펫 · 탈것 · 건축/방 · 등반 · 낚시 · 목장 · 아트 · 날씨
- 날씨는 나중에 한 덩어리로 (사람 결정 2026-09-15) — 스폰할 동식물이 먼저 있어야 비가 의미를 갖는다. 순서: 작물 · 몹 → 날씨
- 경제를 뺀 이유: 엔진이지만 재미의 증명은 아니다
- 멀티를 뺀 이유: 혼자서 "막으면서 캐는" 시간 쪼개기가 재미있으면 둘이면 더 재미있다
- 건축을 뺀 이유: 엔드게임이라 1~3개월로는 검증되지 않는다

## 수치
- 프로토타입 기간: 1~3개월

## 수용 기준
- 프로토타입 한 회차(생활 → 보급 → 원정 → 재료 → 도구 개선)를 끊김 없이 한 번 돌 수 있다

## 미정
- F-17 얼리억세스 원정 섬 2개가 무엇인가 — 추천: 침몰한 마을 + 화산섬 (리듬이 정반대)
