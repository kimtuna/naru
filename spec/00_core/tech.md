# 기술 스택

## 목적
- 엔진·구조의 고정값.

## 규칙
- 엔진 **Godot 4.7 (GDScript)** — 씬·리소스가 텍스트라 diff 가 깨끗하고 AI 도구 연동이 좋다
- **2D 탑다운.** 시점은 어떤 콘텐츠에서도 바꾸지 않는다 (물속·등반 포함)
- 월드는 **시드 기반 절차 생성** — 같은 시드 = 같은 월드
- 중앙 서버는 관문만 (11_multiplayer/central-gateway.md). 게임 시뮬레이션을 안 하므로 부하가 작다
- UI 텍스트를 코드에 박지 않는다 (01_settings/language.md)

## 수용 기준
- 같은 시드로 월드를 두 번 생성하면 결과가 같다
