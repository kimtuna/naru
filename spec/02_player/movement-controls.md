# 이동 · 조작

## 목적
- 이동 · 조준 · 평타(좌클릭) · 상호작용(우클릭) 규칙.

## 규칙
- **이동은 8방향** (사람 결정 2026-09-13) — 대각선을 정규화해 어느 방향이든 속력이 같다
  - 정규화를 안 하면 대각선만 1.41배 빨라 대각으로만 뛰게 된다
- **바라보는 방향 = 마우스.** 이동 방향과 별개 (뒷걸음질 · 게걸음 가능)
- **좌클릭 = 평타** (사람 결정 2026-09-17) — 마인크래프트처럼 **무엇을 들든 휘두른다** (맨손 포함). 총 · 갈고리총은 쏜다
  - **바라보는 방향 앞을 친다** — 커서가 대상 위에 정확히 있지 않아도 앞의 손 닿는 범위 안의 대상이 맞는다
  - 맞은 것이 자원이면 채취가 진행된다. **맞는 도구는 빠르고, 아니면 느리다** (도끼 → 나무, 곡괭이 → 돌 · 광물)
  - 맞은 것이 몹이면 피해가 들어간다 — 채취와 같은 판정 경로를 쓴다
  - **삽을 들고 채집물(약초 등)에 좌클릭하면 채집 스킬체크가 시작된다** (사람 결정 2026-09-18, 04_life/gathering.md)
- **우클릭 = 상호작용** (사람 결정 2026-09-17)
  - **상호작용 오브젝트**: 제작대 · 상자 — 손이 닿는 거리에서 우클릭하면 연다
  - **상호작용 도구 · 아이템**: 들고 우클릭하면 그 아이템의 동작 — 삽 → 개간, 씨앗 → 심기, 음식 → 먹기, 설치물 → 설치
  - 겨눈 곳에 상호작용 오브젝트가 있으면 그쪽이 먼저다
- **되돌릴 수 있다** — 간 밭에 다시 삽 우클릭하면 흙으로 돌아간다 (실수 클릭이 치명적이지 않게)
- 캐릭터 크기는 1칸 방향 (00_core/art-sound.md)

## 수용 기준
- 대각선 이동 속력 = 직선 이동 속력
- 이동 중에도 바라보는 방향은 마우스 쪽이다
- 무엇을 들었든 좌클릭하면 휘두른다 (맨손 포함)
- 커서가 대상 위에 없어도 바라보는 방향 앞 손 닿는 범위의 대상이 맞는다
- 맞는 도구로 치면 맞지 않는 도구 · 맨손보다 빨리 채취된다
- 도달 거리 안의 제작대 · 상자에 우클릭 → 열린다. 좌클릭으로는 열리지 않는다
- 간 밭에 삽 우클릭 → 흙으로 돌아간다

## 미정
- 이동 속력 값 · 상호작용 도달 거리 값 미정
