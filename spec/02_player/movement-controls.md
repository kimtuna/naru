# 이동 · 조작

## 목적
- 좌클릭 하나로 모든 동작을 하게 만드는 규칙.

## 규칙
- **이동은 8방향** (사람 결정 2026-09-13) — 대각선을 정규화해 어느 방향이든 속력이 같다
  - 정규화를 안 하면 대각선만 1.41배 빨라 대각으로만 뛰게 된다
- **바라보는 방향 = 마우스.** 이동 방향과 별개 (뒷걸음질 · 게걸음 가능)
- **좌클릭 = 손에 든 것의 동작.** 총 → 발사, 도끼 → 벌목, 곡괭이 → 채광, 삽 → 채집/개간
- **무엇을 하는지는 「무엇을 겨눴나」가 정한다** — 삽으로 채집물을 치면 채집, 맨땅이면 개간
  - 버튼을 가르지 않는다. 도구가 늘수록 "좌였나 우였나"의 부담이 커진다
- **되돌릴 수 있다** — 간 밭을 다시 치면 흙으로 돌아간다 (실수 클릭이 치명적이지 않게)
- **여는 것도 좌클릭** — 커서가 상자·제작대 위이고 손이 닿는 거리면 도구 동작 대신 연다
  - 안 그러면 상자 위 좌클릭이 도끼질이 되어 상자를 못 연다
- 캐릭터 크기는 1칸 방향 (00_core/art-sound.md)

## 수용 기준
- 대각선 이동 속력 = 직선 이동 속력
- 이동 중에도 바라보는 방향은 마우스 쪽이다
- 같은 도구라도 겨눈 대상에 따라 동작이 달라진다 (삽: 채집물 → 채집, 맨땅 → 개간)
- 간 밭에 삽 좌클릭 → 흙으로 돌아간다
- 도달 거리 안의 상자 위 좌클릭 → 상자가 열리고 도구 동작은 일어나지 않는다

## 미정
