# 인벤토리 · 핫바

## 목적
- 들고 다니는 것의 구조.

## 규칙
- **핫바는 화면 아래 상시 표시** (마인크래프트 · 코어 키퍼 방식). 숫자키로 고른다
- 손에 든 핫바 슬롯의 아이템이 좌클릭 동작을 정한다 (movement-controls.md)
- **빈손으로 시작한다** — 도구를 지급하지 않는다 (04_life/gathering.md)
- 인벤토리는 캐릭터에 붙는다 — 남의 섬에서 캔 것도 따라온다 (11_multiplayer/character-world.md)

## 수치
- 없음

## 수용 기준
- 숫자키 N → 핫바 N번 슬롯이 선택된다
- 새 캐릭터의 인벤토리는 비어 있다
