# 등반

## 목적
- 절벽을 장비로 오르는 PEAK 식 등반을 2D 탑다운에서. **목적은 절벽에만 자라는 약초다.**

## 규칙 (사람 설계 2026-09-16)
- **절벽 타일은 기본적으로 못 간다** — 위 · 아래 · 옆 전부. **신발에 스파이크를 끼워야** 움직인다 (사람 결정 2026-09-17)
- 절벽은 산 · 화산 · 설산에 전부 있다 (03_world/terrain.md)
- **시점을 바꾸지 않는다.** 매달림은 **타일 종류**로 표현한다 (밟는 칸 / 매달리는 칸 / 못 가는 칸)
- **기력**: 절벽을 이동할 때 생기고 준다 (사람 결정 2026-09-17). 다 쓰면 **떨어진다**. **낙하 피해**가 있다 (08_combat/damage-death.md)
- **장비 셋** (사람 결정 2026-09-16)

| 장비 | 무엇 | 기력 |
|---|---|---|
| **스파이크** | 신발에 단다. 절벽 등반을 **가능하게** 한다 | 소모 |
| **앵커** | **소모성.** 절벽 칸에 단다. **그 칸에 있으면 기력이 회복된다** (사람 결정 2026-09-17) | 회복 |
| **갈고리총** | 좌클릭으로 쏜 쪽으로 날아간다. 최대 거리보다 멀리 겨누면 최대 거리에, 짧게 쏘면 거기에 걸린다. **탄창이 있다.** 도착하면 **매달린 상태**. **최대 거리는 갈고리총 등급마다 다르다** (사람 결정 2026-09-17) | — |

- 이름은 「그래플링」이 아니라 **「갈고리총」** — 모르는 사람이 있는 단어라서 (사람 결정 2026-09-16)
- **손과 발이 모드를 가른다** — 스파이크는 발이라 손이 비어 오르면서 캔다. 갈고리총은 손이라 드는 동안 채집을 못 한다 (좌클릭은 손에 든 것의 공격)
- **줄을 끊을 수 있다** — 끊으면 아래로 밟을 수 있는 칸이 나올 때까지 떨어진다 (사람 아이디어 2026-09-16)
- **진행**: 초반 스파이크 + 앵커(기력이 전부) → 중반 빠르지만 짧은 갈고리총 → 후반 갈고리총만으로 이동 (사람 결정 2026-09-16)
  - 후반 갈고리총은 **사기여도 된다** — 그만큼 자원을 많이 먹게 한다. 매달린 상태라 기력 · 앵커는 후반에도 쓰인다 (사람 결정 2026-09-16)
- **모든 섬에서 같은 장비** — 본섬에서도 원정섬에서도 쓴다. 설산은 **엄청 높아서** 앵커를 많이, 좋은 스파이크를 요구한다 (사람 결정 2026-09-16)
- 자원 티어는 본섬에도 있고 원정섬에는 더 희귀한 것이 있다 (사람 결정 2026-09-16)
- 펫 「도약」과 맞물린다 (pets-mounts.md)

## 수치
- 없음

## 수용 기준
- 스파이크 없이는 절벽 칸으로 들어갈 수 없다
- 절벽에서 기력이 0 이 되면 떨어지고 낙하 피해를 받는다
- 앵커를 단 칸에서는 기력이 회복된다
- 갈고리총은 최대 거리까지만 날아가고, 탄창이 비면 쏘지 않는다

## 미정
- 매달린 채로 채집이 되나 · 옆으로 가나 · 기력이 더 빨리 주나
- 기력 · 등급별 최대 거리 · 낙하 피해 값
- 줄 끊기 입력
