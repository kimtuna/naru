# 원정 공통 규칙

## 목적
- 「위험한 곳」은 「적이 센 곳」이 아니라 「돌아오기 어려운 곳」.

## 규칙
- 파티 **최대 4인**
- **딥록 갤럭틱식 탑승** — 선착장 / 헬기 착륙장에 들어가면 출발. 별도 파티 UI 없음
- **티켓** = 입장권 · 보험 · 화폐 배수구. 등급이 오를수록 비싸고, 더 많이 들고 가고, 더 많이 잃을 수 있다
- **반입 제한** — 티켓 등급별 밸류 상한
- **죽음** — 티켓 밸류 안의 장비는 유지, 그 판의 획득물만 상실
- 첫 티켓은 공짜 (또는 최하 등급 무료)
- **한 판 길이는 정하지 않기로 정했다** (사람 결정 2026-09-13) — 끝나는 조건만 정하고 시간은 실측. 매 판 로그를 남겨 그 실측으로 티켓 밸류·보험료를 잡는다
- 섬은 갈 때마다 새로 생성

### 섬을 추가할 때 지키는 뼈대
- 들어간다 → 욕심내며 깊이·높이 간다 → 되돌아갈 수 없어지는 지점 → 목표를 얻는 순간 환경이 적대적 → 왔던 길을 역주행해 탈출
- 탈출은 새 콘텐츠가 아니라 같은 맵의 재해석 — 맵 하나를 두 번 쓴다

| 규칙 | 왜 |
|---|---|
| 섬에 티어를 매기지 않고 난이도만 조정 | 만든 맵을 버리지 않기 위해 |
| 섬은 자원의 「종류」, 난이도는 「양과 품질」을 정한다 | 최상위 광물이 한 섬에만 있으면 사실상 티어 |
| 섬마다 요구 보급이 다르다 | "이번엔 어디 가지?"가 "창고에 뭐가 있지?"와 연결되어 농장이 다각화된다 |
| 전부 탈출 레이스가 되지 않게 | 버티기로 끝나는 섬을 섞는다 |
| 역할을 강제로 나누지 않는다 | PvE 라 모두가 스카웃 |
| 때릴 수 없는 적 + 도구로 푸는 장애물 | 생활 플레이어의 자리 |
- **그래플링은 공통 장비** — 원정의 기본 이동 수단

## 수치
- 파티 최대 4인
- 반입 상한 예시: 전설 장비 부위 3 · 총 5 → 상한 20

## 수용 기준
- 탑승 구역 인원이 4명을 넘을 수 없다
- 사망 시 티켓 밸류 안의 장비는 유지되고 그 판 획득물은 사라진다
- 반입 장비 밸류가 티켓 상한을 넘으면 출발할 수 없다

## 미정
- F-14 난이도를 무엇으로 조정하나 (티어가 없으니 유일한 진행도)
- 티켓 가격 · 등급 수 · 보험료 미정
