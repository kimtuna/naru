# 메뉴

## 목적
- 게임 밖 화면 (시작 · 설정 · 캐릭터/월드 선택).

## 규칙
- **흐름** (사람 결정 2026-09-16): 메인 화면 → 캐릭터 선택 → (빈 슬롯이면) 캐릭터 생성·커스터마이징 → 월드 선택·생성 → 게임
- 메인 화면 항목: 시작 · 설정 · 종료
- **캐릭터 슬롯 3개** (사람 결정 2026-09-16)
- **커스터마이징은 칸(항목)과 선택지만 만든다** — 디자인은 사람이 나중에 넣는다. 항목·선택지는 데이터로 정의해서 코드 수정 없이 바꿀 수 있어야 한다 (사람 결정 2026-09-16)
- **게임 중 ESC = 설정 창** (사람 결정 2026-09-17) — 바로 메인 화면으로 나가면 UX 가 부족하다
  - 가방 · 제작 화면 같은 창이 열려 있으면 **그 창부터 닫는다**. 열린 창이 없으면 설정 창을 연다. 설정 창에서 다시 ESC → 닫힌다
  - 설정 창 항목: 계속하기 · 설정 · 월드 설정(서버장만, 01_settings/world-settings.md) · 메인 화면으로(저장) · 게임 종료(저장)
  - 설정 창을 열어도 월드는 멈추지 않는다 — 세션 서버라 친구가 같이 있을 수 있다 (임시)
- 메뉴 화면(캐릭터 선택 등)에서 ESC = 뒤로
- 캐릭터 선택과 월드 선택이 분리된다 (11_multiplayer/character-world.md)
- 원정 파티 UI 는 만들지 않는다 — 탑승으로 대신 (09_expedition/common.md)
- 텍스트는 번역 키로
