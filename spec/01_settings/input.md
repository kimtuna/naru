# 입력 설정 (키보드 · 마우스)

## 목적
- 키 배치의 기본값. 조작의 동작 규칙은 02_player/movement-controls.md.

## 규칙
| 입력 | 무엇 |
|---|---|
| WASD | 이동 (8방향) (사람 결정 2026-09-13) |
| 마우스 위치 | 바라보는 방향 · 조준 |
| 좌클릭 | 도구 사용 · 상호작용 · 열기 — **하나로 전부** |
| 숫자키 | 핫바 슬롯 선택 |
- 별도 상호작용 키를 두지 않는다. 추가 입력이 필요해지면 그때 정한다

## 수치
- 없음

## 수용 기준
- 입력은 Godot InputMap 액션으로 정의되고 코드는 키 코드가 아니라 액션 이름을 쓴다

## 미정
- 키 재설정(리바인딩) 지원 여부 미정
- 가방 · 메뉴 · 일시정지 키 미정
- 게임패드 지원 여부 미정
