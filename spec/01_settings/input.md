# 입력 설정 (키보드 · 마우스)

## 목적
- 키 배치의 기본값. 조작의 동작 규칙은 02_player/movement-controls.md.

## 규칙
| 입력 | 무엇 |
|---|---|
| WASD | 이동 (8방향) (사람 결정 2026-09-13) |
| 마우스 위치 | 바라보는 방향 · 조준 |
| 좌클릭 | **평타** — 무엇을 들든(맨손 포함) 휘두른다. 총이면 쏜다 (사람 결정 2026-09-17) |
| 우클릭 | **상호작용** — 제작대 · 상자 열기, 설치, 삽으로 개간, 심기, 먹기 (사람 결정 2026-09-17) |
| 숫자키 | 핫바 슬롯 선택 |
- 「좌클릭 하나로 전부」(2026-09-13)는 폐기 — 좌클릭이 평타가 되면서 상호작용은 우클릭으로 갈렸다 (사람 결정 2026-09-17)

## 수치
- 없음

## 수용 기준
- 입력은 Godot InputMap 액션으로 정의되고 코드는 키 코드가 아니라 액션 이름을 쓴다

## 미정
- 키 재설정(리바인딩) 지원 여부 미정
- 가방 · 메뉴 · 일시정지 키 미정
- 게임패드 지원 여부 미정
