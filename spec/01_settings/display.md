# 화면 설정

## 목적
- 해상도 · 창 모드 · 화면 배율.

## 규칙
- 2D 탑다운 픽셀 (00_core/tech.md)
- 플레이어는 맵 전체가 아니라 자기 화면만 본다 — 화면이 꽉 차 있으면 된다
- **기준 화면 640×360** (사람 결정 2026-09-17) — 16px 타일로 가로 40칸 × 세로 22.5칸
- **보이는 범위는 누구에게나 같다** (사람 결정 2026-09-17) — 해상도 · 창 크기와 상관없다. PvP 에서 큰 화면이 이득을 보면 안 된다
  - 카메라 줌처럼 보이는 범위를 바꾸는 플레이어 설정을 두지 않는다
- **16:9 가 아니면 검은 띠** (사람 결정 2026-09-17) — 울트라와이드도 옆을 더 보지 않는다
- **글자 · UI 도 기준 화면에 맞춰 같이 커진다** (사람 결정 2026-09-17) — 창이 커져도 글자만 작아 보이지 않는다
- 도트가 깨끗하도록 정수 배율을 먼저 쓴다 (1280×720 = 2배, 1920×1080 = 3배, 2560×1440 = 4배)
