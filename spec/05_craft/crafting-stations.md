# 제작대 · 타이머 · 출력 버퍼

## 목적
- 초반의 답답함 → 테크·자동화로 풀리는 성취감.

## 규칙
- **제작은 즉시 완성되지 않는다** — 타이머가 돌고, 결과물이 **출력 버퍼**에 쌓이고, 플레이어가 수령한다
- 초반의 답답함은 의도다. 초반부터 편하면 성취가 없다
- 출력 버퍼는 나중에 드론·NPC 주민이 상자로 옮기는 구조가 그대로 얹힌다
- 제작대는 좌클릭으로 연다 (손이 닿는 거리)
- 같은 방 안의 상자를 재료로 바로 쓴다 — 방 ID 일치로 판단 (06_build/rooms.md)
- **제작대는 「점점 올라간다」** (사람 결정 2026-09-15) — 나무 → 돌 → 철처럼 단계가 오르고, 그 단계가 자동화 테크 단계와 같은 축
- 카테고리별로 나눈다. 1판 구상: 가공대(열 없는 가공) · 제련로(열) · 조리대(조합) · 조리용 화로(가열) · 연구대

## 수치
- 없음

## 수용 기준
- 제작 시작 직후 결과물은 버퍼에 없다. 타이머가 끝나야 버퍼에 생긴다
- 수령하기 전까지 결과물은 버퍼에 남는다
- 같은 방 ID 의 상자 재료는 인벤토리에 없어도 제작에 쓰인다

## 미정
- F-16 제작대 계통 수 · 단계 수 · 각 단계가 무엇을 여는지 (회의 필요)
- 버퍼 최대 칸 수 미정
