# 직업

## 목적
- 모두 마스터할 시간이 없게 만들어 시장을 연다.

## 규칙
- 사다리: 견습 lv1~30 → (퀘스트로 전직) → 하급 lv1~50 → … → **마스터**
- **전설 직업**: 퀘스트가 어렵고 노가다성이 심하다
  - **승급 조건에 도감이 들어간다** — 원정 없이 딸 수 있다 (04_life/codex.md)
  - 남의 최종 장비를 대신 제작 · 강화해주는 자리를 얻는다 (10_economy/commissions.md)
- **직업 개수 상한 없음** — 조절할 값은 개수가 아니라 **시간 비용**
  - 전부 마스터한 사람은 그만큼 시간을 쓴 것이고, 시장의 공급자가 된다
- **부캐 허용** — 직업 진행도는 캐릭터마다 처음부터. 총 시간이 같아 지름길이 아니다
- 직업 진행도는 캐릭터에 붙는다
- 캐릭터 레벨(「무엇을 할 수 있나」)과 별개 — 직업은 「무엇을 만들 수 있나」

## 수치
- 없음

## 수용 기준
- 한 캐릭터가 가질 수 있는 직업 수에 상한이 없다
- 새 캐릭터의 직업 진행도는 0 이다
