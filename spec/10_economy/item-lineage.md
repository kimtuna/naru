# 아이템 ID 계보 · 원정 검증

## 목적
- 거래 단위가 곧 검증 단위.

## 규칙
- 모든 경계 재화는 **고유 ID**
- 흐름: 중앙이 광물 #1234 발행 → 경매장에서 소유권 이전 → #1234 로 장비를 만들면 장비 #5678 이 새로 발행되고 #1234 를 품는다 → 원정 입장 시 #5678 계보를 검증 (족보가 없으면 핵)
- 경계 재화 원본은 중앙 원장에 있다
- **중앙이 스탯을 재계산한다** — 등급·재료로 다시 계산 (포인트 예산제, 02_player/equipment.md)

### 원정 결과 검증
- PvE 라 중앙이 검증할 것은 「결과」 하나 — 지연시간 경로에 안 들어간다
- 중앙이 섬 시드 발급 (희귀 배치용 **비밀 소금**은 주지 않는다)
- 호스트가 "몇 초에 어느 칸에서 무엇을" 사건 순서대로 보고 → 중앙이 시드·시간·이동 가능성으로 판정 → 맞으면 ID 발행

| 뚫리는 길 | 막는 법 |
|---|---|
| 시드로 정답표 뽑기 | 비밀 소금 |
| 발도 안 딛고 보고 | 결과가 아니라 사건을 보고 |
| 그래도 뚫림 | 수출 상한 (접속 시간 · 파티 인원 · 완료 횟수) |

### 보고는 호스트를 거치지 않는다
- 획득한 본인 클라이언트가 중앙에 직접 보고 + 호스트도 보고 → 일치하면 **에스크로**
- 탈출 성공 → 확정 지급, 죽음 → 소멸
- 호스트 이탈 시 이미 에스크로된 것은 살아남는다
- **호스트 끊김 시 게스트는 에스크로분을 받고 호스트는 못 받는다** (일부러 끊기 방지)

## 수치
- 없음

## 수용 기준
- 재료 ID 가 없는 경계 장비는 검증에 실패한다
- 호스트 끊김 시 게스트만 에스크로분을 받는다

## 미정
- 수출 상한 계산식 미정
