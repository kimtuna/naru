# 통화 — 광물 본위 · 순환

## 목적
- 별도 게임 머니 없이 인플레를 구조로 막는다.

## 규칙
- **등급이 나뉜 원정 광물이 곧 화폐**
  - 발행이 원정에 묶여 있다 — 세션 서버가 못 찍는 유일한 물건
  - 재료이자 화폐라 「쓸까 팔까」의 긴장이 생긴다 (재미)
- **NPC 는 팔기만 하고 사주지 않는다** — 사주면 내부 재화로 화폐를 찍을 수 있다
- **첫 티켓은 공짜 (또는 최하 등급 무료)** — 가진 게 0 인 신규의 입구
- **중간 등급이 기축**이 되게 산출량을 잡는다 — 최상위는 너무 귀하고 최하위는 너무 흔하다

### 순환
- 수도꼭지: **원정 하나뿐** (중앙 발행)
- 배수구: **티켓 · 보험료 · 제작/세공 수수료** (소각)
- 생활 플레이어 수입은 원정 가는 사람에게서 나온다 — 원정 없이도 돈을 번다

## 수치
- 없음

## 수용 기준
- NPC 상점에는 판매 기능만 있고 매입 기능이 없다
- 티켓 구매 시 지불한 광물은 소멸한다

## 미정
- F-3 광물 등급별 산출량 (중간 등급 기축을 실제 숫자로)
