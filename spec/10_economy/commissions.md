# 의뢰 (수주)

## 목적
- 생활 플레이어의 수입원 — 경매장과 같은 급의 기능.

## 규칙
- 생활 플레이어는 경계 재화가 없어 경매장에 올릴 것이 없다 → 수입은 **남의 재료를 받아 대신 만들어주는 수수료**

| 문제 | 필요한 것 |
|---|---|
| 재료만 받고 먹튀 | **에스크로** — 중앙이 재료를 잠근다 |
| 서버·시간대가 다르다 | **우편 구조** — 주문 게시 → 수락 → 납품. 동시 접속 불필요 |
| 가격을 모른다 | 초기엔 NPC 하한선 · 시세 표시 |
- 전설 직업이 대리 제작·강화를 맡는다 (05_craft/professions.md)

## 수치
- 없음

## 수용 기준
- 의뢰 수락 후 재료는 에스크로에 잠겨 의뢰자·수주자 누구도 임의로 꺼낼 수 없다

## 미정
- 의뢰 취소·기한 초과 처리 미정
