# 자원 재생

## 목적
- 기본 자원이 마르지 않게, 그러나 섬이 플레이어에게 저항하지 않게.

## 규칙
- 재생은 「자원을 구조로 만들라」는 규칙과 별개다 (벌목=수액, 채광=광산 방)

| | 재생 | 왜 |
|---|---|---|
| 나무 | O — 게임 시간 며칠 | 마르면 초반이 막힌다. 베느냐 수액이냐는 선택으로 남는다 |
| 돌 | O — 나무보다 길게 | 마르면 광산 방 재료도 없다 |
| 광물 | O — 가장 길게 | 통화 본위라 흔해지면 경제가 흔들린다. 느려서 광산 방을 지을 동기가 된다 |
| 상위 금속 | X — 원정에서만 | 원정이 공급선이라는 것을 지킨다 |
| 원정 섬 | 갈 때마다 새로 생성 | |

- **재생 = 「없앤 표시를 지우는 것」** — 그 칸이 시드의 원래 값으로 돌아간다
  - 비율이 저절로 지켜지고 섬이 원래보다 빽빽해질 수 없다
  - 「지금 비율을 세어 부족한 만큼 채우기」는 금지 — 순서 의존 계산이 되어 해시가 깨진다
- **사람이 만든 것 둘레에는 안 자란다** — 설치물 · 간 밭 · 길 둘레 몇 칸
  - 안 그러면 「완성된 자기 섬」이 불가능하다
- 플레이어 몸이 서 있는 칸에도 안 자란다

## 수치
- 반경 · 날 수는 눈으로 보고 정한다 (아래 미정)

## 수용 기준
- 재생된 칸의 내용은 같은 시드·좌표의 최초 생성 값과 같다
- 원래 비어 있던 칸에는 재생으로 자원이 생기지 않는다
- 설치물 둘레 반경 안, 플레이어가 선 칸에는 재생되지 않는다
- 재생 주기: 나무 < 돌 < 광물

## 미정
- 종류별 재생 날 수 · 설치물 둘레 금지 반경 값 미정
