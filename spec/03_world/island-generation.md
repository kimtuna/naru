# 섬 생성 (내 섬)

## 목적
- 넓고, 재현 가능하고, 시작이 막히지 않는 섬.

## 규칙
- **시드 기반 절차 생성.** 같은 시드는 항상 같은 월드
- 배치는 좌표를 넣으면 값이 나오는 **해시**여야 한다 — 순서에 달린 계산 금지
- **넓게 잡는다** — 공장을 크게 지을 수 있어야 하고(땅이 곧 천장), 업데이트 확장 자리가 필요하다
- **배치는 비율로 정한다** (사람 결정 2026-09-15)
  - 「땅의 몇 %를 채울까」 하나 + 종류 사이의 비 (예: 나무 3 : 돌 2 : 광물 1)
  - 거기서 칸마다 확률이 따라 나온다. 종류마다 문턱을 따로 두면 하나를 만질 때 나머지가 흔들린다
- **광물은 지형이 정한다** (사람 결정 2026-09-15) — 맵 전체에 고르게 뿌리지 않는다
  - 예: 유황은 화산, 철은 설산 둘레. **개인 섬에도 이런 지형을 둔다**
  - 채광이 「아무 데나 파기」가 아니라 「어디로 가야 하나」가 된다
- **보장**
  - 스폰 지점 7×7 빈터
  - 첫 테크에 필요한 광물의 지형이 시작 섬에 반드시 있다 (없으면 첫 제작대를 못 만든다)
- 내 섬에도 산이 있다 (기본 자원 등반, 04_life/climbing.md)

## 수치
- 크기: 256×256 타일 · 섬 하나 (1판 값)

## 수용 기준
- 같은 시드로 두 번 생성 → 모든 칸이 같다
- 어떤 시드든 스폰 둘레 7×7 에 장애물이 없다
- 넓은 영역에서 센 종류별 개수의 비가 설정한 비율에 근접한다
- 광물은 지정 지형 밖에 생성되지 않는다

## 미정
- 첫 테크에 필요한 광물이 무엇인지 — 제작대 계통(05_craft/crafting-stations.md)과 같이 정한다
- 지형 종류 목록 · 광물-지형 대응표 미정
