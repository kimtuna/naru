# 조건부 스폰

## 목적
- 시간 · 날씨 · 지형 · 계절을 「수집의 변수」로 만든다.

## 규칙
- 일부 동식물은 **조건이 맞아야** 나타나고, 조건이 다 맞아도 **확률로만** 나온다
- 조건 축 (사람 결정 2026-09-15)

| 축 | 예 |
|---|---|
| 시간 | 밤에만 나오는 식물 · 동물 |
| 날씨 | 비 · 눈 · 바람 |
| 지형 | 해안 · 숲 · 고지 |
| 계절 | 위와 겹쳐 조건을 좁힌다 |
- 여러 축이 겹쳐서 스폰을 연다
- **이로치** — 색이 특이한 개체가 낮은 확률로 태어난다. 개체마다 유일
- 원정 섬이 주무대, 내 섬에도 넣는다
- 도감(04_life/codex.md) · 브리딩(04_life/ranching-breeding.md)이 여기에 매달린다

## 수치
- 없음

## 수용 기준
- 조건이 맞지 않으면 해당 종은 절대 스폰되지 않는다
- 조건이 맞아도 확률 판정을 거친다 (확률 1 미만이면 항상 나오지는 않는다)

## 미정
- 종별 조건표 · 이로치 확률 미정
