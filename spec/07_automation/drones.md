# 드론

## 목적
- 배관 대신 드론 — 설치 UX 가 싸다.

## 규칙
- **배관이 아니라 드론** — 배관은 격자 배선이라 화면이 지저분하고 팩토리오·ONI 문법이다
- **거치대 하나가 곧 시설**
- 대가: 「배선을 짜는 재미」를 포기 → **거치대 배치 · 범위 · 충전 동선**이 대신한다
- 역할 예: 급수, 출력 버퍼 → 상자 운반
- 나중: 무인 헬기 농사

## 수치
- 없음

## 수용 기준
- 드론은 자기 거치대 범위 밖에서 일하지 않는다
- 충전이 떨어진 드론은 거치대로 돌아간다

- 거치대 범위 · 드론 배터리 · 드론 종류 미정
- F-6 NPC 주민과 역할이 어떻게 갈리나 (npc-villagers.md)
