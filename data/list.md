# 할 일 목록

사람과 Claude 가 대화로 채운다. 루프가 위에서부터 **순서대로** 처리하고 체크한다.
루프 세션은 이 파일을 읽지 않는다 — 루프가 지금 할 단계만 `current.md` 로 뽑아 준다.

## 형식

- `## [ ] ID 제목` — 묶음. 한 묶음 = 브랜치 하나. 단계가 전부 통과해야 main 에 합친다
- `- [ ] 1. 단계 제목` — 단계. 한 단계 = 루프 한 회차
- `  - 기준: ...` — 수용 기준 (QA 채점표). 단계 밑에 들여 쓴다
- `  - ...` — 기준이 아닌 참고
- 묶음 제목 바로 밑 `- spec: ...` · `- 결정: ...` — 묶음 전체에 붙는 정보
- 표시: `[ ]` 할 일 · `[x]` 끝남 · `[>]` 결정 대기로 넘어감 (`decisions.md`)
- 결정이 나면 `[>]` 를 `[ ]` 로 되돌리고 `- 결정: ...` 을 적는다. 브랜치에 남은 작업에서 이어간다

## [ ] G-102 메인 화면 · 캐릭터 · 월드
- spec: spec/12_ui/menu.md, spec/11_multiplayer/character-world.md, spec/01_settings/save.md, spec/01_settings/language.md
- 결정: 캐릭터와 월드는 따로 만든다. 한 캐릭터를 어느 월드에나 데려간다. 캐릭터 슬롯 3개. 커스터마이징은 칸만 — 디자인은 사람이 나중에 (2026-09-16)
- [x] 1. 저장 뼈대 — 캐릭터와 월드를 따로
  - 캐릭터: 이름 · 외형 선택값 · 인벤토리(빈 목록). 월드: 이름 · 시드 · 만든 시각
  - 기준: 캐릭터와 월드를 각각 저장하고 불러오면 값이 저장 전과 같다
  - 기준: 캐릭터 슬롯은 3개다. 3개가 찬 상태에서 새로 저장하려 하면 거부된다. 캐릭터 · 월드를 삭제할 수 있다
  - 기준: 저장 위치는 `user://` 아래다. 테스트는 임시 경로를 써서 실제 사용자 저장을 건드리지 않는다
- [ ] 2. 메인 화면 · 캐릭터 선택 · 캐릭터 생성
  - 기준: 게임을 실행하면 메인 화면(시작 · 설정 · 종료)이 뜬다. 설정은 빈 자리(뒤로만)
  - 기준: 캐릭터 슬롯 3칸 — 있는 칸은 이름, 빈 칸은 「새 캐릭터」. 빈 칸 → 생성, 있는 칸 → 월드 선택. 삭제는 확인을 한 번 거친다
  - 기준: 생성 화면 — 이름 입력과 외형 항목(몸 · 머리 모양 · 머리 색 · 옷)을 이전/다음으로 바꾼다. 항목과 선택지는 데이터 파일 하나에 있고, 추가하면 코드 수정 없이 나타난다 (테스트). 빈 이름은 거부된다
  - 기준: 미리보기는 기본 도형 3D 캐릭터여도 된다 — 고른 선택지에 따라 바뀐다
  - 기준: 메뉴 화면에서 ESC → 뒤로. 화면의 모든 글자가 번역 키이고 한국어 · 영어가 둘 다 있다
- [ ] 3. 월드 선택 · 생성 → 게임 들어가기
  - 기준: 저장된 월드 목록, 새 월드(이름 · 시드 — 자원 배치용, 비우면 무작위), 삭제(확인 한 번), 뒤로 → 캐릭터 선택
  - 기준: 월드를 고르면 캐릭터와 월드를 들고 게임 씬(빈 3D 씬이면 된다)에 들어간다. 게임 씬은 캐릭터 이름과 월드 이름을 안다
  - 기준: 같은 캐릭터로 월드 X 에서 인벤토리에 넣은 값이 월드 Y 에 들어가도 그대로다 (테스트)

- [x] 2. 캡슐 캐릭터와 3인칭 카메라

  - 기준: 카메라가 캐릭터 뒤 · 위에서 따라가고, 마우스로 돌린다. 화면 가운데에 조준점이 있다
  - 기준: 위아래로 기울이는 각도에 한계가 있다. 캐릭터 뒤에 벽을 두면 카메라가 벽 앞으로 당겨지고, 치우면 원래 거리로 돌아간다 — 원래 거리보다 멀어지지 않는다 (테스트)
  - 기준: 이동은 카메라 기준 8방향이다 — 카메라를 돌리면 W 의 방향이 바뀐다. 대각선 속력이 직선 속력과 같다 (입력 흉내 테스트)
  - 기준: Space 로 점프한다. 점프 높이는 약 1m (임시 — 중력 30 · RoboBlast 처럼 빨리 떨어진다), 공중에서 다시 점프하지 않는다 (테스트)

  - 기준: 이동 속력 · 점프 · 카메라 거리 · 높이 · 감도 · 위아래 각도 한계 값은 한 곳에 있다
- [x] 3. 보이는 범위 고정
  - 기준: 창 크기가 1280×720 · 1920×1080 · 2560×1440 · 2560×1080 · 1280×800 어느 것이든 보이는 월드 범위가 같다 (시야각 · 카메라 거리 고정)
  - 기준: 16:9 가 아니면 남는 곳이 검은 띠이고 더 보이지 않는다. UI 는 기준 해상도에 맞춰 같이 커진다
  - 기준: 보이는 범위를 바꾸는 플레이어 설정(줌 등)이 없다
- [ ] 4. 핫바
  - 기준: 화면 아래에 핫바가 항상 보인다. 숫자키 N → N번 슬롯이 선택되고 그 아이템이 「손에 든 것」이 된다
  - 기준: 핫바 내용은 캐릭터 인벤토리에 속하고 저장했다 불러와도 유지된다
- [ ] 5. ESC 설정 창
  - 기준: 열린 창이 없을 때 ESC → 설정 창(계속하기 · 설정 · 월드 설정(서버장만, 빈 자리) · 메인 화면으로 · 게임 종료). 다시 ESC 또는 계속하기 → 닫힘
  - 기준: 「메인 화면으로」 · 「게임 종료」는 캐릭터와 월드를 저장한 뒤 나간다
  - 기준: 설정 창이 열려 있는 동안 이동 · 카메라 회전 · 클릭이 게임에 들어가지 않고 마우스 커서가 보인다. 게임은 일시정지되지 않는다 — 물리 · 처리가 계속 돈다 (테스트)
